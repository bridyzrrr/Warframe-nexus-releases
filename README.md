# Warframe Nexus — Public Releases

This is the **public installer and source distribution repository** for the
[Warframe Nexus companion](https://nexus-cloud-beta-production.up.railway.app/download).

**Current status:** early bilingual Windows beta. The app uses public
Warframe Market and WarframeStatus data, and an optional on-device game
presence detector. The full private backend, tokens and keys are never published.

Installers are built using this repository's GitHub Actions workflow and
published under **Releases**, after a successful build. Each release includes
a SHA-256 checksum. **The EXE is not publisher-signed or independently
security-certified.** SmartScreen may warn on unfamiliar software.

Warframe Nexus is an independent fan project, not affiliated with
Digital Extremes. Use third-party companions at your own discretion.

Features advertised here must correspond to an actually published release.
